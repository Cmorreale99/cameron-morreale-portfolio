# Wellington Management — Data Architecture & Pipeline Recovery

## Overview

Rebuilt the data foundation of a Python-based investment decision platform supporting ~$153B in insurance assets across 23 countries, used by ~160 investment professionals.

Reverse-engineered an undocumented Oracle database (~250 tables), resolved a critical SQL pipeline failure, and established a production-ready data model enabling the transition from legacy Excel workflows to a scalable application.

**Impact: ~$8M in annual operational efficiency gains.**

---

## Key Contributions

- Reconstructed the data infrastructure underlying a Python-based investment platform managing **$153B in assets across 23 countries**  
- Reverse-engineered a **~250-table Oracle database** with no schema or documentation, inferring relational structure and dependencies  
- Diagnosed and resolved a **critical pipeline failure** by tracing SQL execution dependencies and identifying a missing upstream dataset  
- Rebuilt a **coherent data model** enabling reliable analytics and application-layer workflows  
- Implemented an **analytics override framework** using Python (Pandas, ipywidgets) with validation and auditability  
- Developed **system architecture documentation and diagrams** to clarify data flow and support maintainability  

---

## Business Impact

- Enabled a production system used by **~160 investment professionals globally**  
- Restored a **blocked data pipeline**, unblocking core application functionality  
- Supported migration from **manual Excel workflows → scalable application infrastructure**  
- Delivered approximately **~$8M in annual efficiency gains**, driven by:  
  - 160 users × 10 hours/week × 48 weeks × ~$105/hour

- **Python:** Pandas, ipywidgets
